- **类型**：概念（本课程自创的讨论框架）
- **提出者**：[[夏可君]]（第 3 讲首次展开，自称"这学期我会跟你们谈一个非常神奇的灵魂观"）

## 命题
**不是"我"在记忆，而是灵魂在记忆。**
- 希腊语 ψυχή（psyche）＝心灵／灵魂；讲稿反复追问的是 "what is the soul? how does the soul remember?"。
- 记忆不是个体主体的行为；**场景会自动显现，不需要学习**。

## 三个例证（讲稿的推进顺序）
1. **动物**：老鼠见猫、羚羊见狼，生下来不必学习就知道逃。被吞噬的**惊恐**＋逃逸的**迅疾**，这两个动作构成动物灵魂的全部标志。图像并不清晰，但带着恐惧的图像本身就是灵魂的记忆。
2. **人**：人的灵魂同样担心被吞噬，但多出第二项——**渴望被保护**。"越是面对死亡与被吞噬的恐惧，人类越需要神的手"；由此读**最后的晚餐**（"这是我的身体，是血，你们要吃，你们要饮"）为人类灵魂场景的显现。
3. **电影**：看完三小时电影通常什么都记不住，但伟大的电影必定在某一刻**呈现一个经典场景**（讲稿举《泰坦尼克号》船头展臂的姿势），你不必去记就记住了。"只有塑造了灵魂记忆场景的艺术才是真正的艺术。"

## 与本课程主线的接口
- **盛唐的那个场景**：讲稿把[[霓裳羽衣曲]]＋[[胡旋舞与胡腾舞|胡旋舞]]＋[[王维]]的琵琶＋[[唐玄宗]]的目光四者构成的时刻，称为"**盛唐灵魂出窍与幻化的时刻**"——最美、最令人眩晕、最幻化，也**最后导致了灾难**。
- **幻象的必要**：没有幻象的人平庸，有幻象的人可能被幻象毁灭。讲稿据此给出一张各文明的"幻象自我"清单：
  | 文明 | 要成为的那个幻象 |
  |---|---|
  | 古希腊 | 那喀索斯（水中倒影）——认出自己的那一刻就死去 |
  | 基督教 | 耶稣基督（失去我、受难、获得圣灵之我） |
  | 佛教 | 佛（找回未被熏染的佛性） |
  | 道家 | "吾丧我"、心斋坐忘、同于大通 |
  | 儒家 | 圣人、尧舜、孔子 |
  | [[唐玄宗]] | 梦中所见的**老子玄象** |
  | [[王维]] | **[[维摩诘]]** |
  | [[李白]] | 道士／教导君王者 |
  | [[杜甫]] | 历史盛衰之中的我（《秋兴八首》） |
- 讲稿由此说：西方文化最彻底的美在于**认知的悖论**——认识自己的那一刻就失去自己（那喀索斯、俄狄浦斯、黑格尔《精神现象学》、[[拉康]]的自恋神话）。

## 与"幻热"的关系
灵魂的记忆是[[幻热与热化]]的接受端：热与幻造出场景，而场景之所以能被记住，是因为"灵魂在记忆"。讲稿另引超现实主义（布勒东"美只能是痉挛的"，达利、贾科梅蒂）作为西方版本的"眩晕即美"。
