## 关键洞窟
| 窟号 | 年代 | 本课程用到的内容 |
|---|---|---|
| **第 220 窟** | 初唐（题记 642 年） | 东壁门南维摩诘经变（含帝王图与各族王子）；北壁药师经变中的两组**胡旋舞**与乐队（琵琶、箜篌、阮、筝）。1944 年敦煌艺术研究所剥离清代表层壁画后显露。第一任院长常书鸿称其"构图设色不亚于意大利文艺复兴时期的教堂装饰绘画" |
| **第 103 窟** | 盛唐（712–756） | 东壁门南维摩诘经变，被认为带[[吴道子]]"吴带当风"笔法；北壁右侧十六观竖幅（日想观）——讲稿据此推测"长河落日圆"的图像来源。见 [[十六观想]] |
| 第 172 窟 | 盛唐 | 北壁右侧十六观竖幅，日想观顶部场景 |
| 第 335 窟 | — | 维摩诘经变窟内景 |
| 第 332、419、423 窟 | 隋 | 维摩诘经变早期形态 |
| 第 9、61 窟 | 晚唐、五代 | 维摩诘经变遗存 |
| 第 14 窟 | 晚唐 | 横弹琵琶 |
| 第 112 窟 | 中唐 | **反弹琵琶**、琵琶与古筝 |
| 第 169 窟（炳灵寺） | 420 年前后 | 现存最早的维摩诘经变 |

- 讲稿统计：全国各地绘有维摩诘经变者约 67 例，其中敦煌莫高窟占 58 例。
- 讲稿的一个未决问题：**王维是否到过敦煌**？他到过凉州（武威）、张掖，"西出阳关无故人"已近敦煌，但无实证。见 [[第1讲-历史中的王维与王维所开启的历史]]。
